# RingCentralDemo

We investigated three ways of calling into RC here, with the web widget, with an API and the rest client and with just a simple console.

Obviously we didn't cover the hardest use cases here which would be three legged auth for multiple users and an entire app and multi-user workflow set up, but we did play around with JWT auth level single user workflows long enough to find out that for our purposes RC is not the play here.

We want more automated bot IVR postback behaviour, and albeit this is great for a business phone replacement line or CRM intake it isnt particularly what we are looking for.

Maybe as a business line replacement its good pricing at 30 bucks a month
but the loss of an actual radio uplink makes the product not viable for me.
